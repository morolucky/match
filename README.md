# 🏛️ استوديو مباني الجزائر العاصمة · Building Studio + LevelLighting

أداة ويب ثلاثية الأبعاد (Three.js 0.160) لتصميم مباني الجزائر العاصمة الاستعمارية والموريسكية بكل تفاصيلها:
الأروقة والأقواس، الشرفات بالحديد المشغول، الشيش (Persiennes) الزرقاء، الكوابيل، الكورنيش، القباب، المشربيات، الزليج،
اللافتات، أعمدة الإنارة الكلاسيكية، المكيفات، الصحون الهوائية، الغسيل… مع نظام الإضاءة الكامل (Lumina GI, SSR, GTAO, TAA).

## التشغيل

الملفات عبارة عن ES modules، لذلك يجب فتحها عبر خادم محلي (وليس بالنقر المزدوج على الملف):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الواجهة

| التبويب | المحتوى |
|---|---|
| 🇩🇿 **مصمم الجزائر** | المحرك الجديد: أنواع المباني + كل الخصائص (يُبنى تلقائياً عند التعديل) |
| 🧱 **الاستوديو** | مولّد المباني الأصلي (كما كان) مع أطلس UV وخامات Bake Lab |
| 💡 **الإضاءة** | الوقت، التعريض، Lumina GI، SSR+GTAO، TAA/SMAA، DLSS |
| 📤 **تصدير** | OBJ، GLB، UV Layout، لقطة شاشة |

مدخلات المصمم متنوعة: منزلقات مع حقل رقمي، عدّاد ±، أزرار مقسّمة، مفاتيح تشغيل، لوحات ألوان + منتقي حر،
بطاقات مصورة (الأنواع ونقوش الحديد)، رقائق متعددة الاختيار (حياة الشارع)، ومحرر **برنامج الطوابق** (نوع الشرفة وتاج النافذة لكل طابق).
بالإضافة إلى: تراجع/إعادة (Ctrl+Z / Ctrl+Y)، 🎲 تنويع، 🎰 عشوائي، حفظ/فتح التصميم JSON، بحث في الخصائص،
وحفظ تلقائي في المتصفح. تغيير الألوان ونقش الحديد والقِدم فوري بدون إعادة بناء.

### أنواع المباني

| النوع | مثال في العاصمة | السمات |
|---|---|---|
| هوسماني بأروقة | العربي بن مهيدي | زاوية مشطوفة، أروقة نصف دائرية، شرفتان ممتدتان، درابزين حجري |
| عمارة الزاوية المستديرة | ساحة أودان | زاوية مستديرة، قوس سلّة، كوابيل ضخمة، قبة إمبراطورية |
| آرت ديكو | ديدوش مراد | شرفات منحنية ممتدة، حديد هندسي، طابق متراجع، رولو |
| نيو-موريسكي | البريد المركزي | أقواس حدوة حصان، مشربيات، زليج، شرفات مسننة، قبة بصلية |
| باروكي مزخرف | بن بولعيد | محلات مقوسة، جبهات مثلثة، Pilasters، مانسارد بنوافذ |
| واجهة البحر | زيغود يوسف | واجهة طويلة جداً بأروقة متكررة |
| عمارة شعبية | باب الواد | بسيطة، شرفات منفردة، قِدم واتساخ، حياة شارع كثيفة |

كل نوع هو مجرد مجموعة قيم فوق الخصائص الافتراضية، فيمكن مزج أي شيء بأي شيء.

js/app/                    build.js (إعادة البناء للمحركين) · loop.js (حلقة الرسم + DRS)

  schema.js                القيم الافتراضية + تعريف كل عنصر تحكم (الواجهة تُولّد منه)

  design.js                Store التصميم

  builder.js               المنسّق: يبني المبنى كاملاً ويدمجه
  ctx.js                   سياق البناء: تجميع الهندسة حسب المادة ثم دمجها
  materials.js / textures.js  مواد وخامات إجرائية (جص، حجر، شيش، حديد، زليج، لافتات…)

### خامات PBR وعناصر الشارع
- `js/pbr/labGen.js`: مولّد **Facade Bake Lab** (نفس شيدر الخامات: Albedo / Roughness / Height / AO لـ 28 خامة) مستخرج حرفياً من الملف المرفق.
- `js/pbr/library.js`: يشغّله على لوح مسطّح متكرر بلا فواصل ويُخرج Albedo + Normal + ORM (R=AO, G=Roughness, B=Metalness) بدقة 512 / 1K / 2K.
- `js/pbr/roles.js`: ربط كل مادة في المشهد (جدران، حجر، رصيف، أسفلت، زنك، خشب، معدن…) بخامة، مع مقياس الأمتار لكل تكرار.
- `js/pbr/manager.js`: يولّد ويطبّق الخامات مع ذاكرة مؤقتة (تغيير المقياس أو الألوان لا يعيد التوليد؛ شريط «القِدم» يحرّك العفن والتقشر والتشققات).
- `js/algiers/parts/props.js`: مقاعد، حاويات، أعمدة حماية، أشجار بشبكة، أحواض، كشك، وسيارات متوقفة بخامات PBR.
- من اللوحة: تبويب «مولّد خامات PBR» لاختيار خامة كل دور وتنزيل خرائطه PNG.

### إضافة خاصية جديدة للمصمم
1. أضف القيمة الافتراضية في `DEFAULTS` وعنصر التحكم في `GROUPS` داخل `js/algiers/schema.js` (تظهر في الواجهة تلقائياً).
2. اقرأها في الجزء المناسب داخل `js/algiers/parts/`.
3. إن كانت لوناً أو مظهراً فقط، أضف `look: true` وطبّقها في `applyLook()` لتتغير فوراً بلا إعادة بناء.

### إضافة نوع مبنى جديد
أضف مدخلاً في `TYPES` داخل `js/algiers/types.js`: الاسم، المكان، `patch` (القيم)، و`program(n)` لبرنامج الطوابق.
