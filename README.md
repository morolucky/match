# Maison Modulaire

A browser-based 3D workshop for generating modular Haussmann-style façades. Adjust the building footprint, roofline, architectural modules, and stone patina in the live Three.js preview. Export the building as GLB or generate tileable 1K albedo, roughness, and normal maps.

## Run locally

```sh
npm install
npm run dev
```

Use the sliders and module switches to change the facade. Drag to orbit, scroll to zoom, and use **Export model** or **Generate & export maps** to download assets.

```sh
npm run build
```
