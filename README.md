# نظام أشجار الشوارع AAA — Street Tree System (Procedural PBR)

ملف واحد `index.html` (Three.js r170، بدون خطوات بناء). افتحه عبر أي خادم ثابت، مثل `python3 -m http.server`، ثم زر `http://localhost:8000/`.

## المزايا
- **خرائط PBR إجرائية كاملة للأوراق**: Albedo · Normal · Roughness · Metallic · AO، وقناع ألفا. أطلس 2×2 فيه أربعة أشكال أوراق مسننة، بعروق رئيسية وثانوية وشبكية. عارض خرائط مدمج يتيح تنزيل كل خريطة PNG.
- خامات PBR مولّدة لـ: اللحاء المتشقق (مع أشنات)، حجر الرصيف، الأسفلت، التربة/النشارة، ومعدن العمود.
- **هيكل أغصان بخوارزمية استعمار الفضاء (Space Colonization)**، وسماكة حسب نموذج دافنشي للأنابيب، وأنابيب بإطارات النقل المتوازي، وتوسّع جذور عند القاعدة.
- **أوراق على الأغصان** بترتيب حلزوني (137.5°)، موجّهة نحو الضوء والخارج. أشكال التاج: وسادة مقصوصة، كرة، مكعب، مظلّة، طبيعي.
- **شيدرات مخصصة**: رياح (للأغصان والأوراق والظلال معاً)، نفاذية ضوئية للأوراق (SSS)، وطلاء جير على الجذع (كامل أو شريطين) بحواف غير منتظمة.
- الموقع: رصيف حجري بحواف مشطوفة، وحوض بحواف مرتفعة مع تربة وعشب أو شبكة حديد زهر، وأوراق متساقطة جافة، وعمود إنارة كلاسيكي مضيء، ودعامات اختيارية.
- العرض: ACES، وظلال ناعمة، وبيئة PMREM، وGTAO (يحترم قناع الأوراق)، وBloom، وMSAA مع Alpha-to-Coverage.
- أربعة مستويات جودة (`?quality=low|medium|high|ultra`)، وأربعة أوضاع إضاءة، وستة قوالب، وبذرة قابلة للتكرار.
- تصدير **GLB** (الأوراق بوضع ألفا MASK)، ولقطة PNG، ونسخ ولصق الإعدادات بصيغة JSON.

## English
Single-file procedural street-tree generator. Features: a full procedural PBR leaf map set with a viewer, space-colonization branching, wind/SSS/lime-paint shader injection, GTAO + bloom, quality tiers, and GLB export.
